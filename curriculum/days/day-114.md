# Day 114: System Design Fundamentals

**Teach:** Use a small product prompt and ask clarifying questions before drawing components; estimate scale only after requirements.
**Learn:** Functional/nonfunctional requirements, APIs, data model, bottlenecks, availability, consistency, and tradeoff communication.
**Build:** Design a URL bookmark or task platform on one page, including read/write flow and a scaling bottleneck.
**Interview:** Design a task management service for multiple users; explain requirements and one tradeoff.
**DSA:** Solve a basic rate-limiter design exercise using a token bucket model and discuss boundary behavior.
**Checkpoint:** Student presents a clear diagram and states assumptions, bottleneck, and failure mode.
