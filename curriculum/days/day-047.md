# Day 47: API Contract and Status Codes

**Teach:** Review an endpoint contract before implementation. Ask what response best communicates created, missing, invalid, and unexpected outcomes.
**Learn:** Common 2xx/4xx/5xx codes, request validation, stable response shapes, and error details.
**Build:** Write an API contract for a library endpoint including success and error examples.
**Interview:** When should an API return 400, 404, or 409?
**DSA:** Find the k-th largest element using a min-heap of size `k`; explain complexity.
**Checkpoint:** Student chooses status codes from the operation's outcome, not from a single generic response.
