# Day 43: REST Resource Design

**Teach:** Model URLs as resources, then map common actions to HTTP methods and status codes.
**Learn:** REST constraints at a practical level, resource naming, idempotency, and pagination concepts.
**Build:** Draft endpoints for books, members, and loans with example requests and responses before coding.
**Interview:** What does idempotent mean for an HTTP operation? Give an example.
**DSA:** Count connected components in an undirected graph using DFS or BFS.
**Checkpoint:** Student justifies endpoint names, method choices, and expected status codes.
