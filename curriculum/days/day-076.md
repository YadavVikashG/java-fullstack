# Day 76: Semantic HTML

**Teach:** Inspect a page without CSS and discuss how semantic elements communicate structure to browsers and assistive technology.
**Learn:** Document structure, headings, landmarks, links, forms, labels, buttons, and accessible names.
**Build:** Create the task manager's semantic page skeleton with navigation, task list, and labeled form.
**Interview:** Why choose a `button` instead of a clickable `div`?
**DSA:** Solve meeting-room overlap detection by sorting intervals and scanning.
**Checkpoint:** The page is understandable with CSS disabled and all controls have labels.
