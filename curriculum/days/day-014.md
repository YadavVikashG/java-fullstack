# Day 14: Composition

**Teach:** Draw a has-a relationship and compare it with inheritance. Ask which object should own each behavior.
**Learn:** Object collaboration, composition, dependency direction, and keeping responsibilities focused.
**Build:** Create a `Library` that manages books and members through composed objects rather than one oversized class.
**Interview:** When would you prefer composition over inheritance?
**DSA:** Remove duplicates from a sorted array in place and return the new logical length.
**Checkpoint:** Student can trace a checkout request across collaborating objects.
