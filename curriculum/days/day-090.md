# Day 90: React Routing and Application Structure

**Teach:** Start from user navigation paths and decide which state belongs in the URL versus component state.
**Learn:** Client-side routing, route parameters, nested layouts, not-found pages, and route protection concepts.
**Build:** Add task-list and task-detail routes with loading and not-found states.
**Interview:** What does a client-side router do, and what still happens on a direct page refresh?
**DSA:** Solve maximum path sum in a binary tree and distinguish returned path from global best.
**Checkpoint:** Direct links and browser back/forward navigation behave intentionally.
