# Day 20: Library Model Review

**Teach:** Have the student explain the model before reviewing it. Ask where a new rule would belong and why.
**Learn:** Review encapsulation, composition, interfaces, state transitions, and focused tests.
**Build:** Finish a small in-memory library checkout workflow and add a concise README with run and test steps.
**Interview:** Describe a design decision in your library model and one alternative you considered.
**DSA:** Group anagrams from a list of words; compare canonical sorting keys and frequency signatures.
**Checkpoint:** Student demos a complete workflow, tests a rejected operation, and explains the design without notes.
