# Day 6: Methods

**Teach:** Refactor repeated logic live. Explain parameters, return values, scope, single responsibility, and method signatures.
**Learn:** `static` methods, arguments, return types, local variables, and decomposing a problem into named steps.
**Build:** Split the calculator into input, calculation, and output methods; keep each method focused.
**Interview:** What is the difference between a method parameter and an argument? How do return values support testing?
**DSA:** Write a method that checks whether an integer is prime; test small and boundary values, then discuss complexity.
**Checkpoint:** Student can call their methods and explain each method's input/output contract.
