# Day 45: JDBC CRUD and Repository Boundary

**Teach:** Separate SQL access from domain logic; trace one call through a repository rather than exposing JDBC to every class.
**Learn:** CRUD repository methods, row mapping, generated keys, and the boundary between persistence and domain models.
**Build:** Add JDBC create/find/update methods for books and test them against a disposable PostgreSQL database.
**Interview:** What responsibility belongs in a repository, and what should remain in a service?
**DSA:** Use topological sorting to order courses with prerequisites; detect and report a cycle.
**Checkpoint:** Student can replace or test the repository boundary without moving SQL into console code.
