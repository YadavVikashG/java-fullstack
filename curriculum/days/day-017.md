# Day 17: Enums and Records

**Teach:** Replace ambiguous strings with a finite set of named states; distinguish immutable data carriers from behavior-rich entities.
**Learn:** `enum`, `switch` expressions, records, and choosing a representation from domain meaning.
**Build:** Add loan statuses and a record for a search result; reject invalid state transitions.
**Interview:** When is an enum better than a string, and when is a record a good fit?
**DSA:** Find the majority element if one is guaranteed; compare counting and Boyer-Moore reasoning.
**Checkpoint:** Student can enumerate valid states and explain one invalid transition.
