# Day 108: MongoDB CRUD and Indexes

**Teach:** Start from feed access patterns, then choose document fields and indexes to support them.
**Learn:** MongoDB CRUD, filters, projections, sorting, compound indexes, and explain-plan basics.
**Build:** Store and query activity events by owner and time; cap result size and add a measured index.
**Interview:** How does a compound index's field order relate to query patterns?
**DSA:** Solve a sliding-window maximum with a deque and explain why expired indices are removed.
**Checkpoint:** Student tests the intended filter, pagination/limit, and index-backed query plan.
