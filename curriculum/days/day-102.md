# Day 102: Backups and Recovery

**Teach:** Ask what data loss is acceptable and discuss backup frequency, retention, and restore testing.
**Learn:** Backup versus replication, restore drills, migration rollback limitations, and recovery objectives.
**Build:** Document a database backup/restore procedure for the project and rehearse it against disposable data.
**Interview:** Why is an untested backup not enough?
**DSA:** Solve a union-find connectivity problem and explain path compression and union by rank/size.
**Checkpoint:** Student restores a backup to a separate database and verifies expected records.
