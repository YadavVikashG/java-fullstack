# Day 7: Arrays

**Teach:** Draw array indices and values; ask the student to predict index validity before accessing an element.
**Learn:** Array declaration, initialization, `length`, iteration, mutation, and `ArrayIndexOutOfBoundsException`.
**Build:** Create a score analyzer that reads a fixed set of scores and reports count, total, minimum, maximum, and average.
**Interview:** What does it mean for an array to be fixed-size, and how would you choose a dynamic alternative?
**DSA:** Reverse an array in place with two pointers; explain why only constant extra space is needed.
**Checkpoint:** Student handles first/last indices and tests a one-element array.
