# Day 9: Debugging and Decomposition

**Teach:** Demonstrate breakpoints, stepping, inspecting variables, and converting a vague bug into a reproducible case.
**Learn:** Stack traces, compile-time versus runtime errors, debugging, and small testable methods.
**Build:** Add input checks and fix three seeded defects in the score analyzer; write down each observed symptom and root cause.
**Interview:** How do you investigate a bug that you cannot reproduce consistently?
**DSA:** Find the first index of a target using linear search; return a clear not-found result and analyze complexity.
**Checkpoint:** Student reproduces a bug, locates the failing line, and verifies the fix with a regression case.
