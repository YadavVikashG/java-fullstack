# Day 86: React Components

**Teach:** Identify repeated UI and data flow before extracting components; explain that component boundaries should reflect responsibilities.
**Learn:** JSX, function components, props, composition, and rendering lists with stable keys.
**Build:** Convert task rows, task form, and page shell into React components.
**Interview:** What are props, and why should a child component not mutate them?
**DSA:** Solve top-k frequent elements in Java; review heap choices and complexity.
**Checkpoint:** Student can explain the component tree and fix a missing-key warning.
