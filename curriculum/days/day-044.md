# Day 44: JDBC Connections

**Teach:** Trace a query from application to database and back; emphasize resource cleanup and never concatenating untrusted SQL.
**Learn:** JDBC driver, `Connection`, `PreparedStatement`, `ResultSet`, try-with-resources, and parameter binding.
**Build:** Connect the Maven library project to PostgreSQL and load books using a prepared statement.
**Interview:** Why are prepared statements important for both safety and correctness?
**DSA:** Solve shortest path in an unweighted graph using BFS and reconstruct the path with parents.
**Checkpoint:** Student queries local data, closes resources, and uses bound parameters.
