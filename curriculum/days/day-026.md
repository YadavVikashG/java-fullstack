# Day 26: Lambdas and Functional Interfaces

**Teach:** Start with a named behavior, replace it with a lambda, and discuss when a named method is more readable.
**Learn:** Functional interfaces, lambdas, method references, and basic `Predicate`/`Function` use.
**Build:** Add filtering and sorting to the library search using focused predicates and comparators.
**Interview:** What is a functional interface, and where have you used a lambda?
**DSA:** Find the first and last position of a value in a sorted array with two binary searches.
**Checkpoint:** Student can explain a lambda's input and output types without relying on syntax alone.
