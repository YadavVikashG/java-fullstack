# Day 8: Strings

**Teach:** Compare string equality by value and by reference, then show why immutable strings affect repeated concatenation.
**Learn:** `String` methods, `equals`, `equalsIgnoreCase`, `StringBuilder`, and safe index bounds.
**Build:** Make a text analyzer that counts characters, words, and vowels; define behavior for empty input.
**Interview:** Why should Java strings usually be compared with `equals` instead of `==`?
**DSA:** Determine whether a string is a palindrome while ignoring case and non-alphanumeric characters.
**Checkpoint:** Student tests empty, one-character, mixed-case, and punctuation-containing strings.
