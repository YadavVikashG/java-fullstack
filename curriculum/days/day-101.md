# Day 101: Observability and Logs

**Teach:** Follow a request ID across logs and distinguish logs, metrics, and traces by the questions they answer.
**Learn:** Structured logs, useful context, correlation IDs, basic latency/error metrics, and avoiding personal data in logs.
**Build:** Add request correlation and useful operation logs; record a simple latency/error baseline.
**Interview:** How would you investigate a rise in API errors after a deployment?
**DSA:** Solve accounts merge using a graph or disjoint-set union; explain the model choice.
**Checkpoint:** Student can trace a request without logging passwords, tokens, or unnecessary personal data.
