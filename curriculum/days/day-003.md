# Day 3: Expressions and Input

**Teach:** Ask for a prediction before running each expression. Explain arithmetic, comparison, logical operators, precedence, integer division, and console input.
**Learn:** `Scanner`, operators, parentheses for clarity, and basic input validation.
**Build:** Create a two-number calculator that reads operands and an operation, handles division by zero, and prints the result.
**Interview:** Why can `5 / 2` differ from `5.0 / 2`, and how would you avoid an unintended truncation?
**DSA:** Return the sum of an integer array; handle an empty array explicitly. State complexity.
**Checkpoint:** Student traces an expression and demonstrates one valid and one invalid calculator input.
