# Day 99: CI Pipeline

**Teach:** Map a code change through automated checks and explain why reproducible builds matter before deployment.
**Learn:** Continuous integration, build/test stages, dependency caching concepts, and protected secrets.
**Build:** Add a CI workflow that compiles, runs backend/frontend tests, and reports failures on a pull request.
**Interview:** What checks would you require before merging a full-stack change?
**DSA:** Solve minimum genetic mutation or another unweighted transformation path using BFS.
**Checkpoint:** A clean commit triggers the workflow and a deliberately failing test makes the build fail.
