# Day 39: Indexes and Query Plans

**Teach:** Explain index lookup with a sorted-book analogy, then inspect an `EXPLAIN` plan before and after a useful index.
**Learn:** B-tree index basics, selectivity, write/storage tradeoffs, composite indexes, and `EXPLAIN`.
**Build:** Add an index for a demonstrated frequent lookup and compare query plans on a larger sample dataset.
**Interview:** Why not create an index on every column?
**DSA:** Use a monotonic stack to find the next greater element for each array item.
**Checkpoint:** Student gives evidence for an index choice and names its read/write tradeoff.
