# Day 46: JDBC Transactions and Errors

**Teach:** Revisit atomic checkout and implement transaction boundaries; discuss why a connection should not leak across layers.
**Learn:** Auto-commit, manual commit/rollback, SQL exceptions, and mapping persistence failures to useful application errors.
**Build:** Implement transactional loan creation with rollback on any failed step.
**Interview:** Where should a transaction begin and end in a layered application?
**DSA:** Implement Dijkstra's algorithm for a small nonnegative weighted graph; state its assumptions.
**Checkpoint:** Student tests both successful commit and failure rollback.
