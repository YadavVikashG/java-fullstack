# Day 19: Object-Oriented Testing

**Teach:** Derive tests from behavior and invariants, not from private implementation details. Demonstrate arrange-act-assert.
**Learn:** Unit-test purpose, test cases, assertions, and test seams; introduce JUnit through the project build.
**Build:** Add tests for checkout, return, unavailable books, and invalid loan construction.
**Interview:** What is a unit test, and how is it different from an integration test?
**DSA:** Pair-sum in an unsorted array; begin with nested loops, then use a set and compare complexity.
**Checkpoint:** Tests cover success and failure cases and pass from the build tool.
