# Day 22: Maps and Sets

**Teach:** Derive a lookup requirement and select `Map` or `Set`; discuss keys, uniqueness, hashing, and equality contracts.
**Learn:** `HashMap`, `HashSet`, `put`, `get`, `containsKey`, and average-case lookup caveats.
**Build:** Index books by ISBN and reject duplicate identifiers.
**Interview:** How does a hash map support lookup, and what role do `equals` and `hashCode` play?
**DSA:** Find the first non-repeating character in a string using a frequency map and then preserve encounter order.
**Checkpoint:** Student explains how duplicate keys behave and verifies custom key equality.
