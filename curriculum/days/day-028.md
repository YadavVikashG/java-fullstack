# Day 28: Files and Serialization Basics

**Teach:** Separate domain rules from persistence format; discuss why plain text or CSV needs explicit parsing rules.
**Learn:** `Path`, `Files`, try-with-resources, UTF-8, and defensive handling of malformed data.
**Build:** Save and reload expense entries in a simple CSV file; handle missing files and malformed rows predictably.
**Interview:** Why is try-with-resources preferred for file and database resources?
**DSA:** Implement a simple recursive factorial, then identify its base case and stack-space cost.
**Checkpoint:** Student closes resources safely and tests fresh, existing, and malformed input files.
