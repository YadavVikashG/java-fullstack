# Day 34: Data Definition and SQL Types

**Teach:** Choose column types from domain meaning and show how schema constraints protect data even when clients have bugs.
**Learn:** `CREATE TABLE`, `ALTER TABLE`, integer, text, date/time, numeric, identity keys, and nullability.
**Build:** Create `members`, `books`, and `loans` tables with appropriate types and primary keys.
**Interview:** Why should money generally not use a floating-point column?
**DSA:** Merge two sorted linked lists; explain stable pointer handling and linear complexity.
**Checkpoint:** Student justifies each column's type and nullability from a requirement.
