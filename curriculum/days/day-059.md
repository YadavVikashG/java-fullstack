# Day 59: CRUD API and Pagination

**Teach:** Review resource lifecycle and discuss why returning an unbounded table is a reliability risk.
**Learn:** Create/read/update/delete semantics, pagination, sorting, and consistent page metadata.
**Build:** Add task CRUD endpoints with paginated listing, sorting, and predictable not-found behavior.
**Interview:** How would you design pagination for an API with a large result set?
**DSA:** Find the top `k` frequent values using a frequency map and heap or bucket strategy.
**Checkpoint:** Student tests every CRUD path and confirms page bounds and sort behavior.
