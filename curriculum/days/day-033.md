# Day 33: SQL Filtering and Sorting

**Teach:** Convert natural-language questions into `WHERE` conditions and demonstrate null-safe reasoning.
**Learn:** `WHERE`, comparison operators, `AND`/`OR`, `LIKE`, `IS NULL`, `ORDER BY`, and `LIMIT`.
**Build:** Write queries for available books, overdue loans, and expenses in a date range.
**Interview:** Why does `column = NULL` not work as expected in SQL?
**DSA:** Detect a cycle in a linked list using Floyd's slow/fast pointer method.
**Checkpoint:** Student writes a filter with correct precedence and tests boundary dates.
