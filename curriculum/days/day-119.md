# Day 119: Portfolio and Interview Practice

**Teach:** Have the student present a project as a concise story: problem, decisions, challenge, result, and next improvement.
**Learn:** Resume evidence, project README quality, behavioral STAR answers, interview communication, and role-specific preparation.
**Build:** Finalize resume bullets with measurable evidence, portfolio links, setup instructions, and a two-minute project demo.
**Interview:** Tell me about a technical challenge you faced and how you resolved it; probe for ownership and tradeoffs.
**DSA:** Complete one timed medium-level problem; reserve time to test edge cases and explain complexity.
**Checkpoint:** A reviewer can understand the project and run or inspect it without needing undocumented setup help.
