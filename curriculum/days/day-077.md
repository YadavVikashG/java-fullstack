# Day 77: CSS Fundamentals

**Teach:** Use browser devtools to inspect cascade and computed styles; make one change and predict what it will affect.
**Learn:** Selectors, cascade, specificity, box model, units, and reusable CSS variables.
**Build:** Style the task manager's type, spacing, form controls, and task rows with a restrained design system.
**Interview:** Explain the CSS box model and how `box-sizing: border-box` changes sizing.
**DSA:** Solve insert-interval by locating overlaps and building a merged result.
**Checkpoint:** Student can trace why a style wins and inspect layout dimensions in devtools.
