# Day 113: Asynchronous Messaging

**Teach:** Compare a synchronous API call with a background event workflow; identify delivery, retry, and duplicate-message questions.
**Learn:** Queue, producer, consumer, acknowledgment, at-least-once delivery, idempotent handlers, and dead-letter concepts.
**Build:** Design or prototype an asynchronous activity/notification flow; document what happens on retry and duplicate delivery.
**Interview:** Why should a message consumer be idempotent?
**DSA:** Solve task scheduling with prerequisites using topological order and identify cycle behavior.
**Checkpoint:** Student explains the delivery guarantee and a safe retry strategy without claiming exactly-once by default.
