# Day 112: Caching

**Teach:** Identify repeated work and freshness requirements before introducing a cache; draw cache key, fill, expiry, and invalidation paths.
**Learn:** Cache-aside, TTL, invalidation, stampede risk, and correctness tradeoffs.
**Build:** Add a small cache only to a measured read path; test expiration or invalidation after a write.
**Interview:** Why is cache invalidation difficult, and what consistency does your chosen strategy provide?
**DSA:** Implement an LRU cache and explain how a map plus linked structure meets expected constant-time operations.
**Checkpoint:** Student can state what stale result is possible and how the cache is bounded.
