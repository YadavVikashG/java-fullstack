# Day 32: PostgreSQL Setup and SQL Basics

**Teach:** Connect to a local development database and distinguish the database server, database, schema, and client.
**Learn:** PostgreSQL tools, `SELECT`, `FROM`, aliases, and safe use of a disposable local environment.
**Build:** Create the course database and run basic queries against a small sample dataset.
**Interview:** What is PostgreSQL, and how is a relational database different from a Java collection?
**DSA:** Find the middle node of a linked list using slow and fast pointers.
**Checkpoint:** Student can connect locally and explain which database their query targets.
