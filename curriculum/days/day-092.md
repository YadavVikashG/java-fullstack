# Day 92: Shared State and Server State

**Teach:** Classify example values as local UI state, URL state, or server state before selecting a state tool.
**Learn:** State ownership, lifting state, context tradeoffs, cache invalidation concepts, and avoiding premature global stores.
**Build:** Share task filters between list controls and URL parameters; keep server data handling explicit.
**Interview:** How do you decide where React state should live?
**DSA:** Solve permutations with duplicates using sorting and backtracking with duplicate-skip logic.
**Checkpoint:** Student explains the source of truth for filters and task data.
