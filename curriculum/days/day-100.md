# Day 100: Deployment Fundamentals

**Teach:** Draw the path from browser to frontend host, API, and database; identify what is public and what must remain private.
**Learn:** Build artifacts, environment configuration, TLS, allowed origins, database networking, and deployment environments.
**Build:** Deploy a non-sensitive staging version using a managed host; use separate staging credentials and data.
**Interview:** What configuration changes between local, staging, and production environments?
**DSA:** Solve a minimum-spanning-tree problem with Kruskal's algorithm and a disjoint-set structure.
**Checkpoint:** Staging is reachable over HTTPS, secrets are configured outside source control, and health is verified.
