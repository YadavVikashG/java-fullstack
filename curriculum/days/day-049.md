# Day 49: Logging and Integration Testing

**Teach:** Compare diagnostic logs with user-facing errors and show a test that uses a real disposable database boundary.
**Learn:** Logging levels, structured context, integration-test purpose, and test data cleanup.
**Build:** Add logs around a library operation and an integration test for JDBC repository behavior.
**Interview:** How do unit and integration tests differ, and what does each catch?
**DSA:** Implement a binary search tree lookup and compare its average and worst-case behavior.
**Checkpoint:** Student can diagnose a failed repository test without printing secrets or swallowing the cause.
