# Day 85: Browser Tooling and Frontend Review

**Teach:** Have the student debug a seeded visual or network issue using console, elements, and network panels.
**Learn:** Browser devtools, source maps at a high level, responsive inspection, and client/server responsibility.
**Build:** Polish the standalone task prototype and write down what should move into a component framework.
**Interview:** How would you debug a page that looks correct locally but fails to load API data?
**DSA:** Solve find-all-anagrams-in-a-string with a sliding window and frequency counts.
**Checkpoint:** Student provides a reproducible bug report with browser, steps, expected behavior, and observed behavior.
