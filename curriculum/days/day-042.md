# Day 42: JSON and Data Exchange

**Teach:** Compare a Java object with its JSON representation; identify the contract and why clients should not depend on internal fields.
**Learn:** JSON objects, arrays, primitive values, null, serialization, and naming conventions.
**Build:** Define JSON examples for a book, loan, and validation error; validate them with an API client or parser.
**Interview:** What is JSON, and how does serialization differ from storing a Java object directly?
**DSA:** Implement depth-first graph traversal recursively and iteratively; compare stack behavior.
**Checkpoint:** Student distinguishes a JSON contract from a Java class implementation.
