# Day 40: Transactions and Database Review

**Teach:** Demonstrate a multi-step checkout that must succeed or fail as one unit; introduce ACID using the concrete workflow.
**Learn:** `BEGIN`, `COMMIT`, `ROLLBACK`, atomicity, isolation, consistency, and durability.
**Build:** Make loan creation and book availability changes transactional; test a forced failure and rollback.
**Interview:** Explain ACID and give an example where a transaction prevents inconsistent data.
**DSA:** Evaluate a basic arithmetic expression in postfix notation using a stack.
**Checkpoint:** Student can show that a failed checkout leaves the database unchanged.
