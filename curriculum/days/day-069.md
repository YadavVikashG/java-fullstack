# Day 69: Passwords and Account Safety

**Teach:** Explain why passwords must never be stored in plaintext or reversibly encrypted; review signup abuse and error-message tradeoffs.
**Learn:** Adaptive password hashing, salts, password policy basics, login rate limiting concepts, and secret handling.
**Build:** Add signup/login using a maintained password encoder and generic authentication failure responses.
**Interview:** Why is a slow password hash preferable to a fast general-purpose hash?
**DSA:** Solve longest common subsequence with a two-dimensional DP table and then reduce space if appropriate.
**Checkpoint:** Student verifies stored values are hashes and no credentials appear in logs or source control.
