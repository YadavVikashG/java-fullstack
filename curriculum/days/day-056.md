# Day 56: Spring Data JPA Basics

**Teach:** Compare handwritten JDBC with ORM mapping; emphasize that generated SQL still exists and must be understood.
**Learn:** Entity, repository interface, identifier, persistence context, and basic derived query methods.
**Build:** Persist tasks or books with Spring Data JPA and PostgreSQL; inspect generated schema and SQL in development.
**Interview:** What is an ORM, and what does JPA define versus Hibernate?
**DSA:** Find the longest substring without repeating characters with a sliding window.
**Checkpoint:** Student can save, retrieve, and explain the entity-to-table mapping.
