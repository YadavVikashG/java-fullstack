# Day 94: Frontend Security

**Teach:** Trace untrusted task text into the UI and explain how escaping differs from rendering raw HTML.
**Learn:** XSS, safe rendering, dependency hygiene, token exposure tradeoffs, and why secrets cannot be protected in browser bundles.
**Build:** Review rendering and authentication flows; remove unsafe HTML insertion and ensure no secret is shipped to the client.
**Interview:** What is cross-site scripting, and how does React's normal text rendering reduce risk?
**DSA:** Solve N-Queens for a small board using backtracking and constraint checks.
**Checkpoint:** Student identifies untrusted input sources and demonstrates safe rendering choices.
