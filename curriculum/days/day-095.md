# Day 95: Full-Stack Application Milestone

**Teach:** Ask for a user-centered end-to-end demo and trace one action from React event to PostgreSQL commit and back.
**Learn:** Consolidate React, TypeScript, REST, auth integration, responsive design, testing, and API error handling.
**Build:** Complete the full-stack task manager's core workflow: sign in, create, filter, update, and delete owned tasks.
**Interview:** Draw the architecture and explain how frontend and backend divide validation and responsibilities.
**DSA:** Solve a trie-based prefix search problem; implement insert and search for a small word set.
**Checkpoint:** Fresh setup is documented, the key workflow works, and frontend/backend tests cover important paths.
