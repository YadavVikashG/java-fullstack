# Day 62: Fetching and N+1 Queries

**Teach:** Inspect SQL emitted by a list endpoint and count queries; explain lazy loading and the N+1 pattern with evidence.
**Learn:** Lazy/eager tradeoffs, fetch joins, entity graphs at a high level, and transaction boundaries.
**Build:** Fix a demonstrated N+1 issue for a task list without loading every related object indiscriminately.
**Interview:** What is the N+1 query problem, and how would you detect and address it?
**DSA:** Find a cycle in a directed graph using DFS state or topological sorting.
**Checkpoint:** Student compares query counts before and after the change and describes tradeoffs.
