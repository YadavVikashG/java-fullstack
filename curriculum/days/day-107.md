# Day 107: MongoDB Atlas Setup and Security

**Teach:** Create a development-only Atlas project/cluster and explain database users, network access rules, and connection-string secrecy.
**Learn:** Atlas concepts, least-privilege users, IP/network restrictions, TLS, environment variables, and cost monitoring.
**Build:** Connect a local sample app to a disposable Atlas database; store the URI outside source control and verify access controls.
**Interview:** What must you protect when connecting an application to a managed database service?
**DSA:** Solve LRU cache design using a hash map and doubly linked list; discuss operation complexity.
**Checkpoint:** Connection succeeds from the intended environment, credentials are not committed, and the cluster is not left open to all networks unnecessarily.
