# Day 30: Expense Tracker Milestone

**Teach:** Ask for a demo and requirements traceability. Review one test failure and let the student diagnose it before helping.
**Learn:** Consolidate collections, exceptions, file handling, Maven, tests, and Git commits.
**Build:** Finish the console expense tracker: add, list, filter, total by category, and save/load data.
**Interview:** Explain how you would test a money-total feature, including rounding and invalid values.
**DSA:** Solve Two Sum again without notes; compare the brute-force and hash-map solutions and explain the tradeoff.
**Checkpoint:** Publish a README with setup, sample run, limitations, and tests; student gives a five-minute demo.
