# Day 80: DOM and Events

**Teach:** Trace an event from user action to handler and state update; discuss why direct DOM mutation becomes hard to coordinate.
**Learn:** DOM selection, event listeners, form submission, event bubbling, and safe text rendering.
**Build:** Add a task form and completion toggle to the prototype; render user-provided text as text, not HTML.
**Interview:** What is event bubbling, and how can event delegation use it?
**DSA:** Solve valid parentheses again, this time explain the stack invariant clearly.
**Checkpoint:** Student submits by button and Enter, prevents unwanted page reload, and avoids unsafe HTML insertion.
