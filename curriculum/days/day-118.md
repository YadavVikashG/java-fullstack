# Day 118: Capstone Quality and Security Review

**Teach:** Use a checklist to review functional behavior, access boundaries, validation, error handling, accessibility, and deployment safety.
**Learn:** Code review habits, threat review, test coverage meaning, and prioritizing defects by user impact.
**Build:** Close the highest-risk capstone gaps; add meaningful tests and document known limitations honestly.
**Interview:** Describe a code review comment that changed your implementation and how you evaluated it.
**DSA:** Solve a tree or graph problem of choice, then analyze correctness, complexity, and edge cases aloud.
**Checkpoint:** No known critical access-control issue; main workflow has regression coverage and limitations are documented.
