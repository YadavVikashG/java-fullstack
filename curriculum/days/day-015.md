# Day 15: Inheritance and Polymorphism

**Teach:** Use a small example to show substitutability, then identify when inheritance would create fragile coupling.
**Learn:** `extends`, overriding, `super`, abstract classes, dynamic dispatch, and the Liskov substitution principle at an introductory level.
**Build:** Add a focused notification interface with two interchangeable implementations; avoid forcing unrelated types into a hierarchy.
**Interview:** Explain method overriding and runtime polymorphism with a concrete example.
**DSA:** Find the missing number from values in a known range; compare sum and XOR approaches and their assumptions.
**Checkpoint:** Student can call implementations through a shared type and explain the runtime behavior.
