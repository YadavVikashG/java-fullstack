# Day 96: Docker Fundamentals

**Teach:** Compare an application's runtime environment with the host machine; explain image, container, port, and filesystem.
**Learn:** Dockerfile basics, image layers, containers, exposed ports, and environment configuration.
**Build:** Containerize the Spring API and run it locally with explicit configuration.
**Interview:** What is the difference between a Docker image and a container?
**DSA:** Solve course-schedule feasibility with topological sorting and detect dependency cycles.
**Checkpoint:** Student builds and runs the API container and explains its required environment values.
