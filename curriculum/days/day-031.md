# Day 31: Relational Data Modeling

**Teach:** Start from library and expense requirements; identify entities, attributes, and relationships before drawing tables.
**Learn:** Tables, rows, columns, primary keys, foreign keys, and one-to-many versus many-to-many relationships.
**Build:** Sketch a PostgreSQL schema for members, books, loans, and categories; mark keys and cardinalities.
**Interview:** What problem do primary and foreign keys solve?
**DSA:** Reverse a singly linked list iteratively; draw pointer updates before coding.
**Checkpoint:** Student explains why a loan should reference a member and a book rather than duplicate all their details.
