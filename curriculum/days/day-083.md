# Day 83: TypeScript Fundamentals

**Teach:** Add types to an existing JavaScript function and show how types help development but do not validate untrusted runtime data.
**Learn:** Inference, unions, interfaces/types, optional fields, narrowing, and strict compiler settings.
**Build:** Convert task data and API helper code to TypeScript; type a response and a form payload.
**Interview:** What is the difference between a TypeScript type check and runtime validation?
**DSA:** Solve search-in-rotated-array in TypeScript and preserve a Java implementation for comparison.
**Checkpoint:** Student handles nullable or optional values without using `any` as a shortcut.
