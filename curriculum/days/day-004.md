# Day 4: Branching and Boolean Logic

**Teach:** Start with a real decision rule, translate it to a truth table, then implement `if`, `else if`, `else`, and compound conditions.
**Learn:** Boolean expressions, comparison boundaries, nested conditions, and avoiding duplicated branches.
**Build:** Write a grade classifier with validated score range and clearly defined boundaries.
**Interview:** How do `&&` and `||` short-circuit, and when does that matter?
**DSA:** Find the second-largest distinct value in an array; agree on behavior when fewer than two distinct values exist.
**Checkpoint:** Student tests boundary scores and explains their chosen behavior for invalid input.
