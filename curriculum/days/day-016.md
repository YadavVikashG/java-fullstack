# Day 16: Interfaces and Contracts

**Teach:** Start from required behavior, express a small interface, and show two implementations that honor its contract.
**Learn:** Interfaces, implementation, default methods at a high level, and programming to an abstraction.
**Build:** Define a `BookRepository` interface and an in-memory implementation for the library exercise.
**Interview:** How do interfaces help testing and reduce coupling?
**DSA:** Check whether two strings are anagrams; first use sorting, then discuss character-frequency counting.
**Checkpoint:** Student swaps implementations without changing the library's calling code.
