# Day 81: Asynchronous JavaScript

**Teach:** Use a timeline to compare synchronous work with promises; show pending, fulfilled, and rejected states.
**Learn:** Promises, `async`/`await`, error handling, and avoiding unhandled rejections.
**Build:** Load mock task data asynchronously and show loading, success, empty, and error states.
**Interview:** What does `await` do, and how should a rejected promise be handled?
**DSA:** Solve daily temperatures with a monotonic stack and explain when an item leaves the stack.
**Checkpoint:** Student can describe UI state for both success and failure, not only the happy path.
