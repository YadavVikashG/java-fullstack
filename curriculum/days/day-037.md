# Day 37: Joins

**Teach:** Draw matching rows as a Venn-style relationship, then show how `INNER JOIN` differs from `LEFT JOIN`.
**Learn:** Join predicates, aliases, one-to-many results, and avoiding accidental Cartesian products.
**Build:** Query each loan with member name and book title; include members with no loans in a second query.
**Interview:** When would you use a `LEFT JOIN` instead of an `INNER JOIN`?
**DSA:** Implement a queue using two stacks; state the amortized cost intuition.
**Checkpoint:** Student predicts row counts and explains why a one-to-many join can repeat parent data.
