# Day 91: React Component Testing

**Teach:** Test what a user can observe rather than component internals; demonstrate a test that submits a form and checks the result.
**Learn:** React Testing Library concepts, accessible queries, user events, and deterministic test setup.
**Build:** Test task creation, loading state, validation display, and an API error state.
**Interview:** What should a frontend component test verify, and what should it avoid coupling to?
**DSA:** Solve combination sum with backtracking and explain how pruning works.
**Checkpoint:** Tests describe user behavior and pass without depending on implementation-specific selectors.
