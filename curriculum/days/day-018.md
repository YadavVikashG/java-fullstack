# Day 18: Packages and API Design

**Teach:** Organize the library example by cohesive responsibility and explain how package boundaries help a growing codebase.
**Learn:** Packages, imports, visibility, naming conventions, and designing small public APIs.
**Build:** Separate domain, service, and repository packages; keep implementation details out of the public interface.
**Interview:** What is a Java package, and how do you decide what belongs together?
**DSA:** Rotate an array right by `k`; normalize `k` and compare reversal with an extra-array approach.
**Checkpoint:** Student navigates the project by responsibility and can justify each public method.
