# Day 48: Maven, Configuration, and Secrets

**Teach:** Trace configuration from environment to application and demonstrate why credentials do not belong in source control.
**Learn:** Maven profiles at a high level, environment variables, `.gitignore`, configuration separation, and least privilege.
**Build:** Move the JDBC URL and credentials to local environment/configuration; add a safe example config with placeholders.
**Interview:** How should an application manage database credentials across local and production environments?
**DSA:** Find the median of two sorted arrays conceptually; implement a simpler merge-based version and discuss complexity.
**Checkpoint:** No secret is committed; another developer can configure the app from documented steps.
