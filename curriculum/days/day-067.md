# Day 67: Authentication and Authorization Concepts

**Teach:** Use a scenario to distinguish identity verification from permission checks; map threats before selecting a mechanism.
**Learn:** Authentication, authorization, roles/permissions, least privilege, secure password storage, and session basics.
**Build:** Write an access matrix for anonymous, user, and administrator actions in the task application.
**Interview:** Explain authentication versus authorization with an API example.
**DSA:** Solve the house-robber dynamic-programming problem and derive the recurrence.
**Checkpoint:** Student can state who may perform each operation and where that policy should be enforced.
