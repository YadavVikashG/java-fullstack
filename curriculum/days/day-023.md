# Day 23: Queues, Deques, and Stacks

**Teach:** Act out FIFO and LIFO with physical examples, then map each rule to a Java collection operation.
**Learn:** `Queue`, `Deque`, stack use cases, and `ArrayDeque` as a practical implementation.
**Build:** Add a waiting list for unavailable books and a simple undo history for the console workflow.
**Interview:** When would you use a queue instead of a stack?
**DSA:** Validate balanced parentheses with a stack; test nesting, mismatch, and empty input.
**Checkpoint:** Student traces enqueue/dequeue and push/pop states accurately.
