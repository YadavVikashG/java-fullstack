# Day 21: Lists and ArrayList

**Teach:** Compare arrays and dynamic lists, then predict the cost of indexed access and insertion at different positions.
**Learn:** `List`, `ArrayList`, generics, iteration, and choosing an interface type for a variable.
**Build:** Replace the library's fixed collection with a list and implement add, search, and remove operations.
**Interview:** What is the difference between an array and an `ArrayList`?
**DSA:** Remove duplicates from an unsorted array while preserving first-seen order; use a set and analyze space.
**Checkpoint:** Student selects a collection based on required operations, not habit.
