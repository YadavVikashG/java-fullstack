# Day 2: Variables and Types

**Teach:** Review Day 1 by asking the student to explain compilation. Introduce variables, primitive types, `String`, assignment, and readable names; model tracing values.
**Learn:** `int`, `long`, `double`, `boolean`, `char`, `String`, declarations, initialization, and `System.out.println`.
**Build:** Extend the profile program with typed age, graduation year, and a Boolean enrolled flag. Print a readable summary.
**Interview:** What is the difference between a primitive value and a reference variable? Use `int` and `String` examples.
**DSA:** Count even values in an integer array. Explain loop invariant; target $O(n)$ time, $O(1)$ extra space.
**Checkpoint:** Student predicts values after assignments and explains why names and types make code easier to maintain.
