# Day 78: Layout and Responsive Design

**Teach:** Start from content and constraints; resize the viewport and decide what should reflow rather than merely shrink.
**Learn:** Flexbox, Grid, intrinsic sizing, media queries, and mobile-first responsive layout.
**Build:** Make the task manager usable on narrow and wide screens without horizontal overflow.
**Interview:** When would you choose CSS Grid over Flexbox?
**DSA:** Solve minimum meeting rooms with sorted start/end times or a min-heap.
**Checkpoint:** Student tests a narrow viewport and explains the chosen layout primitives.
