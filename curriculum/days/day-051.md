# Day 51: Spring Boot Orientation

**Teach:** Compare manual Java server setup with framework-managed startup. Explain convention and dependency injection without hiding control flow.
**Learn:** Spring Boot project structure, starters, application entry point, configuration, and embedded server.
**Build:** Create a Maven Spring Boot application and run a health-style endpoint locally.
**Interview:** What does Spring Boot provide beyond the Spring Framework?
**DSA:** Validate a binary search tree using bounds; explain why checking only parent-child pairs is insufficient.
**Checkpoint:** Student starts the app and identifies the entry point, dependency, and listening port.
