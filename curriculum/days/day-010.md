# Day 10: Fundamentals Project Review

**Teach:** Ask the student to demo one console program without reading notes, then review requirements, edge cases, and naming together.
**Learn:** Requirements-to-code workflow, manual test cases, decomposition, and a short project retrospective.
**Build:** Finish a command-line student gradebook that accepts several scores and reports average, grade, and invalid-input feedback.
**Interview:** Walk through a small program you built: what does it do, what edge case did you handle, and what would you improve?
**DSA:** Find the maximum and minimum in one array traversal; explain comparisons and complexity.
**Checkpoint:** Tag or commit the finished project and explain its flow from input to output.
