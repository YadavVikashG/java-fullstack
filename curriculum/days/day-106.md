# Day 106: MongoDB and Document Modeling

**Teach:** Model a changing activity event as a document, then compare embedding and referencing against relational normalization.
**Learn:** Documents, collections, BSON conceptually, flexible schema, indexes, and workload-driven data modeling.
**Build:** Design activity-feed documents for task events; define query patterns and retention needs before choosing fields.
**Interview:** When is a document database a better fit than a relational database, and what tradeoffs follow?
**DSA:** Solve a trie prefix-count problem or implement prefix search with a clear complexity discussion.
**Checkpoint:** Student explains why the activity feed is document-shaped and why core task ownership remains relational.
