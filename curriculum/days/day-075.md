# Day 75: Secure Backend Milestone

**Teach:** Conduct a student-led walkthrough of data flow and threat boundaries; ask for evidence from tests rather than assumptions.
**Learn:** Consolidate migrations, JPA relations, transactions, authentication, authorization, validation, and testing.
**Build:** Finish the authenticated PostgreSQL task API; document setup, API examples, and security decisions.
**Interview:** Explain how the API prevents one user from accessing another user's task and how you tested it.
**DSA:** Solve a basic interval merge problem after sorting; explain complexity and edge cases.
**Checkpoint:** Clean setup, migration, tests, and security boundary all work; no secrets are committed.
