# Day 11: Classes and Objects

**Teach:** Contrast a class blueprint with object instances. Model state and behavior using one cohesive real-world example.
**Learn:** Fields, methods, constructors, `new`, object identity, and instance versus static members.
**Build:** Start a library model with a `Book` class containing title, author, ISBN, and availability.
**Interview:** What is the difference between a class and an object?
**DSA:** Count occurrences of a target value by scanning an array; establish a simple baseline for later collection solutions.
**Checkpoint:** Student creates two distinct `Book` objects and explains which data belongs to each instance.
