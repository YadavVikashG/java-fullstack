# Day 5: Loops

**Teach:** Have the student manually trace a loop before running it. Compare `for`, `while`, and enhanced `for`; discuss termination and off-by-one errors.
**Learn:** Loop initialization, condition, update, `break`, `continue`, and nested iteration.
**Build:** Add a menu loop to the calculator so it repeats until the user chooses to exit.
**Interview:** How do you identify and prevent an infinite loop? Ask for a concrete loop invariant.
**DSA:** Compute the sum from 1 through `n` iteratively and explain the time and space tradeoff versus the formula.
**Checkpoint:** Student traces a loop and tests zero, one, and typical iterations.
