# Day 84: Accessibility and Forms

**Teach:** Complete a task form using only the keyboard and inspect focus order, labels, and error announcements.
**Learn:** Accessible names, focus states, native validation, error association, and color contrast basics.
**Build:** Improve the task form with labels, helpful errors, keyboard support, and visible focus.
**Interview:** Name two accessibility checks you would include in a frontend review.
**DSA:** Solve minimum-size subarray sum with a sliding window; state when the positive-number assumption matters.
**Checkpoint:** Student completes the primary workflow by keyboard and identifies form errors without color alone.
