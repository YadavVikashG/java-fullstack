# Day 72: Authorization and Ownership

**Teach:** Test object-level access, not only endpoint-level roles; demonstrate how guessing another user's identifier can expose data.
**Learn:** Ownership checks, role checks, method security, and avoiding insecure direct object references.
**Build:** Restrict each user to their own tasks and add an administrator-only action with explicit tests.
**Interview:** What is an insecure direct object reference, and how do you prevent it?
**DSA:** Solve minimum path sum in a grid using dynamic programming.
**Checkpoint:** Tests show a user cannot read, update, or delete another user's resource by changing an ID.
