# Day 35: Inserts, Updates, and Deletes

**Teach:** Demonstrate CRUD with a transaction-aware mindset; inspect a `WHERE` clause before any destructive statement.
**Learn:** `INSERT`, `UPDATE`, `DELETE`, `RETURNING`, and parameterized query concepts.
**Build:** Seed library records and implement a checkout/return data workflow using SQL statements.
**Interview:** What risk comes from an `UPDATE` or `DELETE` without a restrictive `WHERE` clause?
**DSA:** Remove the nth node from the end of a list using a two-pointer gap.
**Checkpoint:** Student safely updates one intended row and verifies the affected row count.
