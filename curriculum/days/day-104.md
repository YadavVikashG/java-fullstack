# Day 104: End-to-End Testing and Quality Gate

**Teach:** Select the smallest useful test for each risk and distinguish browser workflow coverage from unit coverage.
**Learn:** End-to-end test concepts, test data isolation, flaky test causes, and quality gates.
**Build:** Automate one critical user journey from sign-in through task creation; run it in CI where practical.
**Interview:** What is the value and cost of end-to-end tests compared with unit tests?
**DSA:** Solve a weighted shortest-path problem and explain when Dijkstra is not valid.
**Checkpoint:** The critical workflow is repeatable and test failure gives an actionable diagnosis.
