# Day 89: React Forms and Validation

**Teach:** Keep server validation authoritative while providing immediate, accessible client feedback.
**Learn:** Controlled forms, submit state, field errors, and mapping API validation responses to fields.
**Build:** Create and edit tasks through the API; prevent duplicate submits and preserve useful server errors.
**Interview:** Why must frontend validation be backed by server validation?
**DSA:** Solve lowest common ancestor in a general binary tree and compare with the BST version.
**Checkpoint:** Student tests valid submission, invalid input, server rejection, and repeated submit.
