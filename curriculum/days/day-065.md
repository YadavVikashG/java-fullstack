# Day 65: Filtering, Sorting, and Query Safety

**Teach:** Translate a search requirement into bounded query parameters and demonstrate allowlisting sortable fields.
**Learn:** Repository query methods, specifications at a high level, pagination limits, and parameterized filters.
**Build:** Add task filtering by status and due date, with validated sorting and capped page size.
**Interview:** How do you prevent a dynamic sort parameter from becoming an injection or reliability problem?
**DSA:** Solve longest increasing subsequence with a quadratic DP baseline, then discuss the optimized approach.
**Checkpoint:** Student tests combined filters, invalid sort values, and maximum page size.
