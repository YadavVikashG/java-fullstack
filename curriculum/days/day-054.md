# Day 54: DTOs and Mapping

**Teach:** Compare database entities with public API contracts and discuss why exposing persistence objects can create coupling.
**Learn:** Request/response DTOs, mapping, serialization, and stable API boundaries.
**Build:** Create book response and create-book request DTOs; ensure internal fields are not exposed accidentally.
**Interview:** Why use DTOs instead of returning JPA entities directly?
**DSA:** Search a 2D matrix with a defined row/column ordering; state the exact precondition.
**Checkpoint:** Student can change an internal field without silently changing the API contract.
