# Day 111: Profiling and Performance Budgets

**Teach:** Establish a measurable user or API latency goal before optimizing; distinguish CPU, database, network, and rendering costs.
**Learn:** Profiling, latency percentiles, throughput, memory, and interpreting measurements.
**Build:** Measure one slow endpoint or UI flow, form a hypothesis, and test a narrowly scoped improvement.
**Interview:** Why is average latency insufficient for understanding user experience?
**DSA:** Solve a prefix-sum range query problem and explain preprocessing versus query tradeoffs.
**Checkpoint:** Student records baseline, change, and after-measurement rather than claiming an unmeasured speedup.
