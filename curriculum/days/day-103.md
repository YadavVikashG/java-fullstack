# Day 103: Release and Rollback

**Teach:** Walk through a release checklist and discuss backward-compatible schema changes and rollback limits.
**Learn:** Release artifacts, staged rollout concepts, migrations, rollback strategy, and post-deploy verification.
**Build:** Write a release checklist for the app and rehearse a change that remains compatible with the previous version.
**Interview:** How would you safely deploy a database schema change used by two application versions?
**DSA:** Solve search suggestions using a trie and discuss memory/time tradeoffs.
**Checkpoint:** Student can describe deployment, verification, and recovery steps in order.
