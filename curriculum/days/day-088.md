# Day 88: Effects and Data Loading

**Teach:** Separate rendering from synchronization with an external system; explain effect dependencies using a concrete data fetch.
**Learn:** `useEffect`, cleanup, dependency lists, and stale request risks; avoid placing derived calculations in effects.
**Build:** Load tasks from the API and handle loading, error, empty, and success states.
**Interview:** When is an effect appropriate, and why can a missing dependency cause a bug?
**DSA:** Solve subtree-of-another-tree using recursive structure comparison.
**Checkpoint:** Student can explain when the request starts and how the UI handles an unmounted or stale request.
