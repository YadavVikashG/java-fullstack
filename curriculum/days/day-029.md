# Day 29: Maven and Automated Tests

**Teach:** Read a `pom.xml` together and trace how dependencies, source folders, and test lifecycle fit the build.
**Learn:** Maven coordinates, dependency scopes, `mvn test`, JUnit assertions, and keeping tests deterministic.
**Build:** Convert the expense tracker to a Maven project; add unit tests for totals, categories, and invalid amounts.
**Interview:** What does a build tool such as Maven do, and how are test dependencies different from runtime dependencies?
**DSA:** Generate all subsets of a small array recursively; draw the decision tree and explain exponential output size.
**Checkpoint:** A clean checkout builds and tests using documented Maven commands.
