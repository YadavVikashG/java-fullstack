# Day 63: DTO Mapping and Query Design

**Teach:** Start from a client response requirement and select an explicit query/projection rather than serializing an entity graph.
**Learn:** DTO mapping choices, projections, avoiding recursive JSON relationships, and selecting only needed fields.
**Build:** Return a task list DTO with owner display data and pagination metadata.
**Interview:** How can returning entities directly create performance or security problems?
**DSA:** Find all paths from source to destination in a small directed acyclic graph using backtracking.
**Checkpoint:** Student can point to the query and mapping that supply each response field.
