# Day 68: Spring Security Filter Chain

**Teach:** Trace an HTTP request through the security filter chain before it reaches a controller.
**Learn:** Security configuration, authentication providers, request matchers, and secure-by-default route policies.
**Build:** Require authentication for private task endpoints and expose only a deliberate public route.
**Interview:** Where does Spring Security enforce authentication in a request lifecycle?
**DSA:** Solve unique paths in a grid using dynamic programming; explain the state and boundary conditions.
**Checkpoint:** Automated requests prove public and protected routes behave as intended.
