# Day 53: First REST Controller

**Teach:** Map the written API contract to a controller method and explain why transport concerns should stay at the boundary.
**Learn:** `@RestController`, mapping annotations, path variables, query parameters, and response bodies.
**Build:** Expose read-only endpoints for listing and finding books; exercise them with an API client.
**Interview:** What is the role of a controller in a layered Spring application?
**DSA:** Find a target in a rotated sorted array with modified binary search.
**Checkpoint:** Student explains the path from HTTP request to controller response.
