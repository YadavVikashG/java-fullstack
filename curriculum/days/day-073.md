# Day 73: Spring Web and Service Tests

**Teach:** Choose a test slice from the behavior under test; avoid mocking every collaborator without a reason.
**Learn:** JUnit, Mockito basics, Spring MVC test support, service unit tests, and test naming.
**Build:** Test validation/error responses and service rules; cover one authorization boundary.
**Interview:** What makes a test brittle, and when would you use a mock?
**DSA:** Solve decode-ways counting with DP; explicitly handle zero and invalid prefixes.
**Checkpoint:** Tests are deterministic, focused on observable behavior, and run in the standard build.
