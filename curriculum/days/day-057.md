# Day 57: Request Validation

**Teach:** Turn requirements into field constraints and show that client-side validation does not replace server-side validation.
**Learn:** Bean Validation annotations, `@Valid`, constraint messages, and validation boundaries.
**Build:** Validate task title, description length, and due date; return a useful client error for invalid requests.
**Interview:** Why must validation happen on the server even when the frontend validates?
**DSA:** Find the maximum sum subarray using Kadane's algorithm; test all-negative input.
**Checkpoint:** Student tests valid and invalid payloads and distinguishes validation from business-rule conflicts.
