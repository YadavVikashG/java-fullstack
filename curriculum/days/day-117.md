# Day 117: Capstone Architecture and First Slice

**Teach:** Review data model and API contract before implementation; ask the student to identify security and deployment risks early.
**Learn:** Vertical slices, architecture diagrams, migration-first data changes, and incremental delivery.
**Build:** Implement one complete capstone slice from React screen through Spring service to PostgreSQL; add tests as it is built.
**Interview:** Explain one end-to-end feature and why its data belongs in the selected database.
**DSA:** Re-solve a linked-list or stack problem without notes; explain invariants before coding.
**Checkpoint:** One user story works end to end and can be demonstrated from a clean branch.
