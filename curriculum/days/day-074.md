# Day 74: Database Integration Tests

**Teach:** Compare mocked repositories with real database tests and explain why database behavior can differ from an in-memory substitute.
**Learn:** Testcontainers or disposable test databases, migration execution, fixtures, and cleanup.
**Build:** Run repository and migration tests against PostgreSQL in an isolated test environment.
**Interview:** Which bugs can an integration test catch that a mocked unit test cannot?
**DSA:** Solve partition equal subset sum using dynamic programming and explain the state compression idea.
**Checkpoint:** Tests start from a clean schema and do not depend on a developer's personal database state.
