# Day 52: Dependency Injection

**Teach:** Show direct construction coupling, then inject an interface. Trace object creation and explain the container's role.
**Learn:** Beans, constructor injection, component scanning, and why field injection is usually avoided.
**Build:** Add service and repository beans using constructor injection; verify startup wiring.
**Interview:** What is dependency injection, and how does it improve testability?
**DSA:** Find lowest common ancestor in a binary search tree using its ordering property.
**Checkpoint:** Student can trace which component creates and supplies each dependency.
