# Day 60: Spring API Milestone

**Teach:** Ask the student to demo the contract first, then inspect controller, service, repository, and database responsibilities.
**Learn:** Consolidate Spring Boot, dependency injection, DTOs, validation, JPA, and centralized errors.
**Build:** Complete the first task management REST API slice with PostgreSQL persistence and API documentation.
**Interview:** Trace one request through all layers and explain where a new business rule would go.
**DSA:** Solve a binary-tree maximum-depth problem recursively and iteratively.
**Checkpoint:** Automated tests pass, sample requests are documented, and invalid input receives intentional responses.
