# Day 97: Docker Compose and Local Services

**Teach:** Draw the local service topology and show how service names, ports, and persistent volumes differ.
**Learn:** Compose services, networks, health checks, volumes, and local-only secrets/configuration.
**Build:** Run the API and PostgreSQL together in a local Compose setup with migrations and persistent development data.
**Interview:** How do containers discover one another in a Compose network?
**DSA:** Solve number of islands with BFS or DFS and test boundary cells.
**Checkpoint:** One documented command starts the local stack; no production credential is embedded in the compose file.
