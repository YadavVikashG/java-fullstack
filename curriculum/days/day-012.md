# Day 12: Encapsulation

**Teach:** Show how unrestricted public fields allow invalid states; refactor toward private state and intentional operations.
**Learn:** Access modifiers, getters, setters, invariants, and why not every field needs a setter.
**Build:** Add a `Member` class with validated member ID and methods that express allowed changes.
**Interview:** What is encapsulation, and how does it protect an object's invariants?
**DSA:** Move all zeroes to the end of an array while preserving nonzero order; discuss in-place strategy.
**Checkpoint:** Student demonstrates that invalid member data cannot be introduced through the public API.
