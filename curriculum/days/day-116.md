# Day 116: Capstone Scope and Requirements

**Teach:** Help the student choose a problem they can validate with users; turn an idea into a small MVP and explicit non-goals.
**Learn:** User stories, acceptance criteria, risk list, scope control, and project planning.
**Build:** Write capstone README draft, user flows, MVP criteria, database choice rationale, and a short delivery plan.
**Interview:** How do you decide what to leave out of an MVP?
**DSA:** Re-solve a representative array/hash-map problem under a 30-minute timebox, narrating assumptions.
**Checkpoint:** Capstone has a testable user problem, bounded MVP, and success criteria.
