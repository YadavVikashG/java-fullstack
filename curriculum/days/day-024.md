# Day 24: Generics

**Teach:** Show a raw collection's runtime cast risk, then refactor to a parameterized type.
**Learn:** Type parameters, generic methods, compile-time type safety, and reading a simple bounded type parameter.
**Build:** Create a small generic `Page<T>` value that represents a slice of results and metadata.
**Interview:** Why do generics improve safety, and what does type erasure mean at a high level?
**DSA:** Implement binary search on a sorted array; state its precondition and logarithmic complexity.
**Checkpoint:** Student explains why a list of one type is not automatically a list of its subtype.
