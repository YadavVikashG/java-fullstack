# Day 82: HTTP Fetch and API Errors

**Teach:** Inspect a network request in devtools and distinguish transport failure from an HTTP error response.
**Learn:** `fetch`, request methods, JSON parsing, headers, status checks, and aborting stale requests conceptually.
**Build:** Connect the prototype to the Spring API and show clear loading, empty, and error states.
**Interview:** Does `fetch` reject its promise for an HTTP 404? Explain how to handle it.
**DSA:** Solve longest consecutive sequence with a set and explain expected linear-time reasoning.
**Checkpoint:** Student verifies request payload, response, and failure behavior in the Network panel.
