# Day 41: HTTP and the Web

**Teach:** Trace a browser request and response; distinguish client, server, DNS/TCP as context, and HTTP semantics.
**Learn:** URLs, methods, headers, body, status codes, statelessness, and request/response inspection.
**Build:** Use a browser or API client to inspect requests to a public test endpoint and record method, status, and headers.
**Interview:** What happens at a high level when a browser requests a URL?
**DSA:** Implement breadth-first traversal of a graph using a queue; explain visited-state tracking.
**Checkpoint:** Student can read a request and response without confusing headers and body.
