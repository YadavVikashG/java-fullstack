# Day 79: JavaScript Values and Functions

**Teach:** Compare Java's static types with JavaScript's runtime values; demonstrate strict equality and avoid implicit coercion.
**Learn:** `const`/`let`, primitives, arrays, objects, functions, scope, and strict equality.
**Build:** Add a small browser-side task filter using plain JavaScript before introducing a framework.
**Interview:** What is the difference between `let` and `const`, and what does `const` not make immutable?
**DSA:** Solve product-of-array-except-self in JavaScript and compare it with the Java version.
**Checkpoint:** Student predicts value types and can explain a closure in a simple example.
